# Research baseline — 2026-08

この文書はCodex再構築時の**調査基準メモ**です。ゲーム内部式の公式仕様書ではありません。
公開攻略DB・検証記事・PK先行情報を、旧Streamlit版と比較するための証拠として整理します。

## 原則

- 三国志真戦由来の式を信長真戦へそのまま流用しない。
- 公開検証記事の推定式も「仮説」として扱い、確定内部式として固定しない。
- 数値は設定化し、ゲーム内戦報との比較で差し替えられるようにする。
- 編成記事は本文を転載せず、武将・戦法・兵種・兵学・出典URLなどの構造化情報だけを保持する。
- 武将/戦法IDは既存masterとの互換を維持する。

## 3. ダメージ計算 — 信長真戦の実測証拠

主要参考:
- https://www.sanguo-zhi.com/entry/damage-01/

2026-07公開の対人実測記事では、約990本の条件付き検証から次の傾向が報告されている。

### 兵刃/通常攻撃

- 最低保証（floor）が存在する観測。
- 概念的には「最低保証 + 兵力由来 + 属性差由来」の構造が示唆される。
- 属性差が不利でも最低保証部分までは削られない観測。
- 兵力1000時の通常攻撃最低保証は約 `18.75`。
- 低兵力帯はフラット、高兵力帯は単純線形から若干外れるため、全領域を単純比例1本で扱わない。

記事中の目安として扱う値:

| 兵力 | 通常攻撃floorの目安 |
|---:|---:|
| <=600 | 約11 |
| 1000 | 18.75 |
| 1500 | 約28 |
| 2000 | 約37 |
| 2500 | 約46 |
| 3000 | 約55 |
| 3500 | 約64 |

これらは**校正用観測値**であり、公式内部式そのものとは断定しない。

### 戦法ダメージ

- 兵力1000時に `約20.5 × 戦法ダメージ率` という別floor基準が示唆される。
- 通常攻撃floorと戦法floorを同じ定数にしない。

### 乱数・丸め

- 表示ダメージにおよそ `±4%` の変動があるという推定。
- 最終表示で切り捨てが関与するという推定。

新エンジンでは少なくとも以下を設定値にする。

```ts
interface DamageModelConfig {
  normalFloorAt1000: number
  tacticFloorAt1000: number
  randomVariance: number
  roundingMode: "floor" | "round"
  troopCurve: "linear" | "piecewise"
  levelAttributeScale: Record<number, number>
}
```

初期候補:

```ts
{
  normalFloorAt1000: 18.75,
  tacticFloorAt1000: 20.5,
  randomVariance: 0.04,
  roundingMode: "floor",
  troopCurve: "piecewise"
}
```

**注意:** この初期候補を「正解」として固定しない。戦報比較テストで更新する。

### レベルと属性差

公開検証では、武勇1ポイントの寄与がレベルで変化する観測がある。
記事中ではLv20付近とLv50付近で異なる係数が示唆されているため、属性差係数は固定1本にしない。

## 8. エンジンモード

比較可能性を維持するため、計算モデルを分離する。

- `legacy_sangokushi`: 旧版互換・差分確認
- `nobunaga_calibrated`: 信長実測で校正
- `experimental`: 仮説検証

旧版を即削除/上書きしない。
代表編成 + seed固定で旧版と新エンジンを並べ、差分理由を説明できる状態にしてから標準モデルを切り替える。
